Composites

Composites assemble atoms and/or other composites for a particular context.

  • Tool — The contextual description of a Tool maintained by the system.
  • Member — The contextual description of a Member maintained by the system.
  • Reservation — A temporary commitment that holds one Tool for one Member.
  • Checkout — The record of a Member borrowing a Tool.
