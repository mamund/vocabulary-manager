Atoms

Atoms are stable leaf terms.

  • toolId — A stable identifier for a Tool.
  • toolName — The name used to identify a Tool to Members and Tool Supervisors.
  • toolDescription — A description of a Tool and its intended use.
  • memberId — A stable identifier for a Member.
  • memberName — The name of a Member.
  • memberEmail — The email address associated with a Member.
  • reservationId — A stable identifier for a Reservation.
  • reservedAt — The date and time at which a Reservation was established.
  • expiresAt — The date and time at which an unfulfilled Reservation expires.
  • checkoutId — A stable identifier for a Checkout.
  • checkedOutAt — The date and time at which a Tool was checked out by a Member.
  • dueDate — The date and time by which a checked-out Tool is expected to be returned.
  • returnedAt — The date and time at which a checked-out Tool was returned.
