Affordances

Affordances are leaf terms naming domain behaviors; inputs and returns are defined later in the API Story.

  • addTool — Add a Tool to the managed inventory.
  • searchAvailableTools — Search for Tools that are available for borrowing.
  • reserveTool — Reserve an available Tool for an active Member who has no other active Reservation or Checkout.
  • cancelReservation — Cancel an active Reservation before its Tool is checked out.
  • checkoutTool — Acknowledge that a Member has taken possession of the Tool reserved for that Member.
  • returnTool — Acknowledge the return of a checked-out Tool.
  • inspectTool — Assess a Tool's condition and determine whether it should remain in circulation or become outOfCommission.
  • retireTool — Permanently remove a Tool from service while retaining its record for historical purposes.
  • addMember — Add a Member to the system.
  • searchForMember — Search for a Member maintained by the system.
  • updateMember — Update information maintained about a Member, including membership status.
  • searchCheckoutHistory — Search retained Checkout records representing Tool borrowing and return history.
